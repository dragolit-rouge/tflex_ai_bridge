# T-FLEX CAD AI Bridge
Мост автоматизации для **T-FLEX CAD 18 (Учебная версия)**, позволяющий управлять САПР с помощью любой локальной модели через макрос-лаунчер.

Используйте .NET 4(.)8, совместимую с Учебной версией 18.

О файлах в корневой папке:
Файл ai_assistant - заглушка для подключения любой модели, вставьте нужный код (я использовала маленький квен на 3б)

О файлах в папке плагина:
При необходимости в файле TFlexPlugin.csproj нужно изменить путь к API файлу - он всегда находится в программных файлах самого TFlex.
Сердце всего моста - файл Class1 - он компилирует сервер и перезапускается командой "dotnet build". После каждой компиляции он подменяет файл TFlexPlugin и закрывает TFlex самостоятельно.


# Пошаговый запуск:

1. Прописываем в Терминале dotnet build (находясь в папке TFlexPlugin)
2. Запускаем TFlex и выполняем макрос-лаунчер через окно Alt+5 !открываем также пустой файл 3д модели!
3. Запускаем модель командой python ai_assistant.py в корневой папке проекта
4. Работаем с моделью в терминале или дополнении по типу roo code
(5.) При работе с моделью используем библиотеки из папки knowledge

# Самые частые ошибки (будет дополняться)

Если не проходит подключение к порту TFlex - нужно поменять номер порта, убедившись, что макрос работает
Возможно для корректной работы модели ей нужно поставить таймаут чуть больше имеющегося
Из-за неполной загрузки синтаксиса в маленькие модели, необходимо запрещать им галлюцинировать - пример промпта есть в файле ai_assistant.py
