# T-FLEX CAD AI Bridge
Мост автоматизации для **T-FLEX CAD 18 (Учебная версия)**, позволяющий управлять САПР с помощью любой локальной модели через макрос-лаунчер.

Используйте .NET 4(.)8, совместимую с Учебной версией 18.

О файлах в корневой папке:
Файл ai_assistant - заглушка для подключения любой модели, вставьте нужный код.
Файл test_send - проверка работы макрос-лаунчера перед запуском подключения модели. Если что-то идёт не так на этом этапе - в корневой папке появляется файл со словом "error", с описание ошибки в самом макросе - !чаще всего это ошибка пути к файлу TFlexPlugin.dll!

О файлах в папке плагина:
При необходимости в файле TFlexPlugin.csproj нужно изменить путь к API файлу - он всегда находится в программных файлах самого TFlex.
Сердце всего моста - файл Class1 - он компилируется и перезапускается командой "dotnet build". Учитывайте, что после каждой компиляции необходимо подменять файл TFlexPlugin (доставать из папки net48 и перетаскивать в корень), а также очищать кэш TFlex - перезапускать программу.


# Пошаговый запуск:

1. Прописываем в Терминале dotnet build (находясь в папке TFlexPlugin)
2. Подменяем файл TFlexPlugin
3. Запускаем TFlex и открываем MacrosLauncher, компилируя его в окне редактирования макросов на вкладке Инструменты и выполнив через окно Alt+5 (может появится окно создания переменных - "ок" или ничего - это норма) !открываем также пустой файл 3д модели!
4. В терминале запускаем скрипт тестирования командой python test_send.py (проверяем связь и появление тестовой переменной в TFlex)
5. Если всё работает — запускаем модель командой python ai_assistant.py и работаем далее с моделью
